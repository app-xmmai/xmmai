XMM AI — Cloudflare setup (Pages + Worker)
==========================================

1) PAGES (your website)
   - You already have: https://xmmai.vercel.app  (or similar)
   - Upload the contents of this folder to Pages
   - Important: upload so that /chat works
     (index.html at root + chat/ folder)

2) WORKER (hides the Groq key)
   a. Go to: https://dash.cloudflare.com/?to=/:account/workers-and-pages/create
   b. Create a Worker (name it e.g. xmm-groq)
   c. Paste the code from WORKER.js
   d. Deploy
   e. Settings → Variables → Add secret:
        Name:  GROQ_API_KEY
        Value: your Groq key (gsk_...)
   f. Copy the Worker URL (https://xmm-groq.xxxx.workers.dev)

3) CONNECT THEM
   - Open chat/config.js
   - Set:
        GROQ_PROXY: "https://YOUR-WORKER-URL.workers.dev"
   - Leave GROQ_KEY: ""
   - Re-upload only the changed config.js (or whole site) to Pages

4) TEST
   - Open https://xmmai.vercel.app/chat
   - Send a message
   - If it works, the key is safely on Cloudflare and never in the browser

Notes
-----
- .env.example is only a reminder. Never put real keys in frontend files.
- Images use Cloudflare Workers AI through the same Worker (see IMAGES below).
- Allowed origins in WORKER.js already include *.vercel.app, *.pages.dev and your old freedev.app domain.

UPDATE — long files / "cut off" fix
-----------------------------------
- WORKER.js no longer clamps output to 900 tokens. Re-paste it into your Worker and Deploy.
  Optional Worker variable MAX_OUT lowers the ceiling (default 16384 = model maximum).
  Open the Worker URL in a browser: it now shows "max_output_tokens".
- chat/config.js has TIER: "free" or "dev".
    free = Groq free plan (~8K tokens/minute). Big sites are written in chunks that are
           stitched together automatically; expect a short wait between chunks.
    dev  = Groq Developer plan (250K tokens/minute). Big files stream in one go.
  Set TIER to "dev" after upgrading at console.groq.com.
- SECURITY: older builds shipped an obfuscated Groq key inside app.js. It has been removed,
  but the key was public. Revoke it at console.groq.com/keys and use only the Worker secret.

IMAGES — separate Cloudflare image Worker + Pollinations fallback
-----------------------------------------------------------------
1. Create/open the Worker xmmai-image (https://xmmai-image.xbm-bayat.workers.dev).
2. Paste WORKER-IMAGE.js and Deploy.
3. Worker -> Settings -> Bindings -> Add -> Workers AI -> Variable name: AI   (exactly "AI")
4. chat/config.js already has IMAGE_PROXY set to that URL.
5. Free plan = 10,000 neurons per DAY (resets daily, no monthly limit). FLUX at 4 steps = well over 100 images/day.
   Check real usage: Cloudflare dashboard -> Workers AI.
6. Each user can make 1 image per 20 seconds.
7. If the Worker fails or the daily allowance runs out, the site falls back to Pollinations automatically.
